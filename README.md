# FIAP Tech Challenge — Fase 3

Projeto acadêmico de um pipeline local para preparação de dados, anonimização,
fine-tuning com LoRA e demonstração de um assistente de apoio clínico com
LangChain e LangGraph. O subprojeto Python está em
[`fine-tunning-llm/`](fine-tunning-llm/); suas instruções de instalação,
preparo local, execução e segurança estão no
[`fine-tunning-llm/README.md`](fine-tunning-llm/README.md).

Pré-requisitos: Python 3.12, ambiente virtual e os artefatos locais exigidos
pelas etapas do pipeline. Este material é exclusivamente acadêmico: o
assistente não deve ser usado para diagnóstico, prescrição, conduta ou qualquer
decisão clínica real. Toda saída requer avaliação de um profissional habilitado.
